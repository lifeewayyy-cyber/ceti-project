# Сжатие изображений: RLE и энтропия Шеннона

Практический эксперимент по теме lossless-сжатия: почему однородный кадр сжимается сильно, а «шумный» почти не сжимается.


## Идея

В учебных материалах обычно считают только объём «сырого» растра (`ширина × высота × глубина цвета`) и почти не разбирают теорию сжатия. Здесь на двух фото со смартфона сравниваются:

- алгоритм **RLE** (Run-Length Encoding): вместо `AAAAA` записывается `5A`;
- **информационная энтропия Шеннона** \(H = -\sum p_i \log_2 p_i\).

На однородном кадре (белый лист / закрытый объектив) повторы длинные, энтропия низкая, коэффициент сжатия высокий. На текстурном кадре (трава, улица, стол) серии короткие, энтропия выше, RLE почти бесполезен.

## Что делает скрипт

1. Загружает `simple.jpg` и `complex.jpg`, приводит к 200×200, grayscale.
2. Квантует яркость с шагом 16, чтобы подавить микрошум.
3. Кодирует и декодирует пиксели RLE и проверяет, что восстановление без потерь.
4. Считает объёмы RAW / RLE, коэффициент сжатия \(K = V_{raw} / V_{rle}\) и энтропию.
5. Строит гистограммы яркостей и сравнительные графики.

Схема адаптивного квантования и delta-кодирования — в `illustration.svg`.

## Запуск

Нужны Python 3, [Pillow](https://pypi.org/project/Pillow/) и [matplotlib](https://pypi.org/project/matplotlib/).

```bash
pip install pillow matplotlib
python code.py
```

Положите рядом со скриптом файлы `simple.jpg` и `complex.jpg`. В консоли появятся метрики по каждому кадру, затем откроется окно с графиками.

## Вывод эксперимента

RLE хорошо работает там, где соседние пиксели часто совпадают. Высокая энтропия означает более равномерное распределение яркостей и слабое сжатие простым кодированием длин серий — поэтому «пустые» данные сжимаются легко, а «шумные» почти нет.
